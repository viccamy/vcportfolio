# Vitória Camilly · Portfólio

Meu portfólio profissional, criado para apresentar minha trajetória, competências e experiências com **análise de dados, Business Intelligence e automação de processos**.

O projeto conecta minha formação em Administração à prática da tecnologia, com estudos de caso sobre automação de rotinas, visualização de indicadores e análise de informações transacionais.

## Sobre mim

Sou Vitória Camilly, formada em Administração pela Universidade Federal de Campina Grande (UFCG). Minha experiência reúne dados, operações e automação, com ferramentas como SQL, Looker Studio, Google Sheets e Google Apps Script.

Além do trabalho, meu universo também inclui meus três gatos, livros e crochê — interesses que ganharam um espaço próprio no portfólio.

## Executar localmente

Baixe o repositório ou faça um clone e abra o arquivo `index.html` no navegador.

Se preferir usar um servidor local e tiver Python instalado, execute na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000).

> A cópia de e-mail depende das permissões do navegador. Quando o acesso à área de transferência não está disponível, o site mostra o endereço para cópia manual.

## Publicar na Vercel

1. Na Vercel, escolha **Add New → Project**.
2. Importe este repositório do GitHub.
3. Selecione **Other** em **Framework Preset**.
4. Deixe os comandos de instalação e compilação vazios e defina **Output Directory** como `.`.
5. Clique em **Deploy**.

O arquivo `vercel.json` já contém a configuração de hospedagem estática. Mantenha `index.html` na raiz do repositório ou selecione a pasta que o contém em **Root Directory**.

Com a integração configurada, novos commits na branch de produção podem ser publicados automaticamente pela Vercel.

## Personalização

- **Textos e links:** edite `index.html`.
- **Estudos de caso:** atualize o objeto `cases` em `script.js`.
- **Cores e layout:** ajuste `styles.css`.
- **Relevos e sombras:** edite `neumorphism.css`.
- **Currículo:** substitua `assets/curriculo-vitoria-camilly.pdf`, mantendo o nome para preservar o link de download.

Na primeira visita, o tema acompanha a preferência do dispositivo. Quando a pessoa escolhe outro modo, essa preferência é salva localmente no navegador, quando disponível.
